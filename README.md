# Thin_Skin_Diary · 薄肌营养日记

> 一个由 AI 驱动的个人饮食记录与营养分析系统。  
> 目标：通过每日拍照、营养计算与多层级报告，逐步达到并保持“薄肌”体型。

## 📌 项目简介

本项目用于存放每日饮食记录、营养数据、AI 分析结果以及周/月/季/年报告。  
所有日记以 Markdown 文件形式保存，命名格式为：`YYYY-MM-DD_薄肌营养日记.md`。  
仓库根目录下同时包含 AI 私人营养师系统提示词，方便随时调用大模型进行分析。

## 🎯 核心目标

- 每日拍照记录三餐，由 AI 估算热量、蛋白质、脂肪、碳水等营养素。
- 追踪蛋白质摄入，确保达到薄肌饮食推荐范围（1.6–2.2 g/kg 体重）。
- 生成每日汇总、周报、月报、季度报告和年度报告。
- 结合辽宁地域饮食特点，给出个性化调整建议。
- 长期维护个人营养数据库，实现数据驱动的体型管理。

## 🤖 AI 私人营养师系统提示词

本项目的核心是一套为 DeepSeek 等大模型设计的超长系统提示词，包含：

- 用户画像（辽宁男生，2000 年出生，薄肌目标）
- 拍照识餐与营养计算流程
- 每日 MD 文件生成规范
- 周报、月报、季度报告、年度报告模板
- 长期记忆与知识库更新机制

## 🚀 如何使用

1. **每日记录**：将三餐照片发给 AI，根据提示词要求 AI 输出营养数据。
2. **生成日记**：让 AI 按规范生成当天的 Markdown 日记，保存到本仓库。
3. **更新目录**：在 README 的“日记目录”表格中新增一行。
4. **周期报告**：每周/月/季/年让 AI 基于已有日记生成汇总报告。
5. **持续优化**：根据报告调整饮食策略，并更新 AI 提示词中的用户参数。
